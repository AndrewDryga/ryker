Run it

Ryker runs as an Elixir release backed by PostgreSQL on one trusted host. This page covers the shortest path from a checkout to a verified service.

What you need

  • The Erlang and Elixir versions pinned in .tool-versions.
  • PostgreSQL, Coop, a Slack workspace app, and the required Emisar access.
  • A trusted Unix host and systemd for the production service.

Install

shell

git clone https://github.com/AndrewDryga/responder ryker
cd ryker
make elixir-install

The install target builds, inspects, and installs the immutable release under ~/.local/lib/ryker-elixir. Production releases use the same archive and the shipped installer.

Configure

Start from config/ryker-elixir.example.yaml and deploy/systemd/ryker.env.example. Keep platform tokens out of YAML, use distinct Coop policies for production and evaluation, and keep all listeners except authenticated webhook ingress on loopback.

Create the Slack app from deploy/slack-app-manifest.yaml and follow the repository’s Slack app guide for scopes, Socket Mode, and event subscriptions.

Start and verify

Run the release qualification before installing or restarting production:

shell

make release-check
scripts/deploy.sh
curl --fail http://127.0.0.1:4321/healthz
curl --fail http://127.0.0.1:4321/readyz

Then use /manual-tests for the guided Slack, GitHub, webhook, model-behavior, and restart journeys. A green offline gate, an installed release, a ready process, and live platform acceptance are separate evidence.
